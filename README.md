# Interactive Theatre Ticketing

A Web & Mobile I project built with HTML, CSS, and JavaScript.
The theatre has 144 seats in three sections: VIP (50 AZN),
Standard (30 AZN), and Economy (15 AZN).

## Run the project

Open the project folder in VS Code. With Live Preview installed,
right-click `index.html` and choose **Show Preview**.

## Use the theatre map

Click a seat to see its details and price. Use **Add to Cart**
to add an available seat and **Remove** to take it out of the cart.
The map updates the seat colors, and the cart shows the total price.

Use the zoom and direction buttons to explore the map. **Reset View**
fits the full theatre into the map area again. The browser saves
the cart in `localStorage`, so it remains after a page refresh.

## Mouse and trackpad navigation

Point at the seating map and use the mouse wheel or scroll with two
fingers on a trackpad to zoom. Hold the primary button and drag to pan.
Use **Reset View** to fit the whole theatre back into the map area.
